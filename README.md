\# Course Registration Assessment



This project implements:



\- Enrollment

\- Course drop

\- FIFO waitlist

\- Waitlist promotion

\- Prerequisite validation



\## Setup



Install dependencies:



pip install pytest



\## Run Automated Tests



python -m pytest -v



\## Run Manual Test



python manual\_test.py



This script demonstrates:



\- Enrollment

\- Waitlisting when capacity is full

\- FIFO waitlist promotion

\- Prerequisite validation

\- Duplicate enrollment handling
